# 직관 승리요정 · 기획 기록

> 직관 간 경기를 골라 넣으면, 팀 시즌 성적보다 내가 간 날 얼마나 더 이기는지로 "진짜 승리요정"인지 판정해 주는 토스 미니앱(앱인토스)

- 개인 프로젝트 · 혼자 기획 · 디자인 결정 · QA · 출시, 개발은 AI(Claude Code)와 함께
- 2026.11.18 소재 찾기 → 2026.11.24 첫 검토 요청 · 승인 · 출시
- 토스 앱에서 "직관 승리요정" 검색 · 경기 결과 수집기 공개 저장소 [jikgwan-fairy-data](https://github.com/kmj62990680-ux/jikgwan-fairy-data)

> **이 프로젝트는 기획 문서 5종(요구사항 · 기능 명세 · 정책 등)을 먼저 쓰지 않았습니다.**
> [바꾸](../01_bakku/) · [프리패스](../02_freepass/)는 문서를 먼저 쓰고 팀이 나눠 만드는 방식이었고, 이 앱은 혼자 AI와 바로 만들면서 **결정과 근거를 그때그때 기록**하는 방식이었습니다. 이 폴더는 그 기록을 출시 뒤(2026.11) 읽기 좋게 정리한 것입니다. 문서를 나중에 만들어 끼워 넣지 않았습니다.
