# 직관 승리요정 · 기획 문서

> 직관 간 경기를 골라 넣으면, 팀 시즌 성적보다 내가 간 날 얼마나 더 이기는지로 "진짜 승리요정"인지 판정해 주는 토스 미니앱(앱인토스)

- 대상: 국내 프로 스포츠 직관 팬 (농구 · 배구 · 야구 · 축구, 7개 리그)
- 상태: 2026.11.24 출시, 운영 중 · 토스 앱에서 "직관 승리요정" 검색
- 경기 결과 수집기: [jikgwan-fairy-data](https://github.com/kmj62990680-ux/jikgwan-fairy-data)

## 처음 보는 사람은 이 순서로

1. [서비스 정의](docs/01_service-definition.md): 누구의 어떤 문제를, 어떤 기능으로 푸는지
2. [결정 기록](docs/02_decision-log.md): 사용자의 문제 → 고른 것 → 이유 (D-01 ~ D-06)
3. [QA](docs/03_qa.md): 무엇을 확인했고, 사용자에게 어떤 문제를 막았는지
4. [출시와 운영](docs/04_launch-and-operation.md): 지표 설계와 다음 개선
