# 01 서비스 정의

## 1. 한 줄

직관 간 경기를 고르면, 팀 성적보다 내가 간 날 얼마나 더 이겼는지로 진짜 승리요정인지 알려 준다.

## 2. 문제

- 팬들은 "내가 가면 이긴다"고 말하지만 근거는 기억뿐이다.
- 기존 직관 기록 앱은 따로 설치해야 하고, 대부분 야구 전용이며, 내 승률만 보여 준다.
- 내 승률만 보면 강팀 팬은 누구나 승리요정이 된다.

## 3. 대상

| 항목 | 내용 |
|---|---|
| 누구 | 국내 프로 스포츠 직관 팬, 20대 중심 |
| 원하는 것 | "내가 가면 이긴다"를 숫자로 확인하고 자랑하기 |
| 불편한 것 | 몇 번 갔고 몇 번 이겼는지 세기 어렵다 |

### 쓰는 순간

1. **처음 열 때:** 다녀온 경기를 목록에서 체크하면 바로 판정이 나온다.
2. **직관 다녀온 날:** 경기를 고르면 공식 결과가 자동으로 채워진다.
3. **자랑하고 싶을 때:** 승률 카드를 저장해 공유한다.

## 4. 핵심 기능

| 기능 | 내용 |
|---|---|
| 경기 골라 넣기 | 팀을 고르면 최근 경기가 펼쳐지고, 고르면 결과가 자동으로 채워진다 |
| 한 번에 넣기 | 지난 경기를 목록에서 체크해 한 번에 기록한다 |
| 판정 | 팀 시즌 승률 대비 차이로 5단계 판정, 이유 문장 |
| 승률 카드 | 판정과 승률을 담은 9:16 이미지 저장 · 공유 |
| 직관 일기 | 날짜순 기록, 사진과 한 줄 메모 |

- 결과 자동 반영 7개 리그: KBL, WKBL, V리그 남녀, KBO, K리그1, K리그2

## 5. 판정 기준

| 차이 (내가 간 날 승률 − 팀 시즌 승률) | 판정 |
|---|---|
| +15%p 이상 | 승리요정 |
| +5%p 이상 | 행운의 직관러 |
| ±5%p 안 | 보통 직관러 |
| −15%p까지 | 아슬아슬 직관러 |
| 그 아래 | 패배요정 |

- 같은 3승 1패라도 강팀 팬은 **행운의 직관러 +10%p**, 약팀 팬은 **승리요정 +48%p**다.
- 3경기 미만은 "승리요정 후보"로 두고 몇 경기 더 가면 판정되는지 알려 준다.

## 6. 차별점

1. 팀 성적 대비 판정
2. 농구 · 배구까지 7개 리그, 1년 내내 사용
3. 공식 결과 자동 반영
4. 토스 안에서 설치 없이 사용
