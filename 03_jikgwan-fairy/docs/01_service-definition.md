# 01 서비스 정의

| 항목 | 값 |
|---|---|
| 기준일 | 2026-11-24 (출시 시점) |
| 형식 | 앱인토스 웹 미니앱 (React + 토스 디자인 시스템 TDS) |
| 관련 | [결정 기록](02_decision-log.md) · [출시와 운영](05_launch-and-operation.md) |

## 1. 한 줄

직관 간 경기를 골라 넣으면, **팀 성적보다 내가 간 날 얼마나 더 이기는지**로 진짜 승리요정인지 알려 주는 직관 일기.

## 2. 문제

- 직관 팬은 "내가 가면 이긴다 / 진다"를 자주 말하지만 근거가 기억뿐이다.
- 이미 있는 직관 기록 앱은 따로 설치해야 하고, 야구 전용이고, **내 승률만** 보여 준다(2026-11-24 검색 기준). 원래 강한 팀의 팬은 누구나 승리요정이 된다.

## 3. 대상

- 국내 프로 스포츠 직관 팬, 20대 중심 (앱인토스는 만 19세 이상만 이용 가능)
- 출시 시점에 시즌 중인 농구 · 배구 팬을 먼저

## 4. 핵심 기능

| 기능 | 내용 |
|---|---|
| 경기 골라 넣기 | 종목 → 팀을 고르면 최근에 안 적은 경기가 바로 펼쳐지고, 고르면 날짜 · 상대 · 점수 · 결과가 공식 기록으로 채워진다 |
| 한 번에 넣기 | 지난 경기를 달별 목록에서 체크해 한 번에 기록한다 (첫 방문에 바로 판정을 받게) |
| 판정 | 팀 시즌 승률 대비 내가 간 날 승률의 차이(%p)로 5단계 판정 + 이유 문장 |
| 승률 카드 | 판정 · 차이 · 직관 수를 담은 9:16 이미지를 저장 · 공유 |
| 직관 일기 | 해마다 날짜순 기록, 사진 · 한 줄 메모 |

- 자동 반영 리그 7개: KBL · WKBL · V리그 남 · 여 · KBO · K리그1 · K리그2. 그 밖 종목은 직접 입력(무승부 포함).

## 5. 판정 기준

| 차이 (내가 간 날 승률 − 팀 성적대로면 기대 승률) | 판정 |
|---|---|
| +15%p 이상 | 승리요정 |
| +5%p 이상 | 행운의 직관러 |
| ±5%p 안 | 보통 직관러 |
| −15%p까지 | 아슬아슬 직관러 |
| 그 아래 | 패배요정 |

- 3경기 미만이면 "승리요정 후보" 또는 "판정 중"으로 두고, 몇 경기 더 가면 판정되는지 알려 준다.
- 기대 승률 = 내가 간 경기마다 그 팀의 시즌 승률을 평균낸 값. 승률 = 승 ÷ (승 + 패), 무승부는 따로 표시.

## 6. 뺀 것과 이유

| 뺀 것 | 이유 |
|---|---|
| 로그인 · 서버 저장 | 첫 사이클은 "출시 → 숫자 → 고치기"를 한 번 끝내는 게 목표. 기록은 기기에 저장하고 화면에 알린다 |
| 광고 | 첫 버전은 핵심 경험에 집중 |
| 다른 사람과 순위 비교 | 서버 필요, 반응을 본 뒤 |
| 구단 로고 | 상표 · 저작물 문제와 검토 반려 위험. 팀 이름 글자만 쓴다 |

## 7. 차별점

1. 팀 성적 대비 판정 ("팀이 원래 강해요"까지 말해 준다)
2. 농구 · 배구 포함 7개 리그라 1년 내내 쓸 수 있다
3. 공식 결과 자동 반영이라 입력이 짧고 결과를 속일 수 없다
4. 토스 안에서 설치 없이 연다
