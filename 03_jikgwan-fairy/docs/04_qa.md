## 3. 토스 앱에서만 나온 버그: 승률 카드

크롬 시험은 통과했는데 토스 앱에서는 저장이 안 되거나, 저장된 카드에 캐릭터가 빠졌다.

1. 저장 대신 공유 창이 뜸 → 새 저장 함수로 바꾸고 실패 이유를 이벤트로 남김
2. 여전히 실패 → 사진 쓰기 권한 선언, 이미지 크기 축소
3. 저장은 되지만 캐릭터가 빠짐 → 그림을 미리 데이터로 바꿔 넣음
4. 아이폰 엔진 시험에서는 나오는데 토스 앱에서는 여전히 빠짐 → HTML을 이미지로 찍는 방식 자체가 토스 iOS 웹뷰에서 그림을 못 담는다고 판단
5. **카드를 캔버스에 직접 그리는 방식으로 교체** → 토스 앱에서 정상 확인

- 배운 것: 아이폰 사용자가 많으니 시험을 크롬만 돌리지 않는다. 그래서 같은 시험을 아이폰 엔진으로도 돌리게 바꿨다(42개).

## 4. 출시 뒤 운영 중 사고: 수집기 멈춤 (11/25)

- 증상: 모든 리그 결과 업데이트가 멈춤
- 원인: 한 축구 리그 누리집이 해외 서버(GitHub)에는 팀 이름을 영어로 줘서, "모르는 팀 이름" 안전장치가 수집기 전체를 멈춤
- 고친 것: ① 한국어로 요청 ② 한 리그가 실패해도 나머지는 반영하고 실패한 리그는 이전 결과 유지
- 배운 것: 수집 대상은 접속 위치에 따라 다른 응답을 줄 수 있다. 한 곳의 실패가 전체를 멈추지 않게 나눠 둔다.
