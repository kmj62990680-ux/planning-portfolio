### X-01-1 알림 발송 · 알림 목록

> 교환 요청 · 새 메시지 · 약속 취소 · 교환 확인 푸시를 보내고(1차 4종, 상황별 문장은 2차), 알림 목록에서 누르면 해당 화면으로 간다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 1차 | P0 | REQ-X-01 | P-07-04, P-07-03 | 4-01 |

- **1차에서 빠지는 부분:** 상황별 전용 문장 · 알림 목록의 "새 메시지" 상황 저장 · 자동 완료 알림 (F-03-1) · 운영 안내 (P1)
- **예외 · 제약:** 푸시가 꺼져 있어도 앱 안 알림 목록에는 쌓임
- **비고:** 알림 진입은 상단 아이콘 (확정). v0.5.2 (10/30~10/31): 자동 완료 마지막 알림 · 운영 안내 알림 추가. 11/16: 1차 푸시를 4종으로 줄임 — 1차 일정 안에 문구 · 화면을 다 맞추기 어렵고, 약속 · 글 수정 · 삭제는 채팅방에 카드 · 안내로 올라와 "새 메시지"로 알려도 들어오면 확인할 수 있음. 약속 취소 · 교환 확인은 놓치면 헛걸음하거나 완료 처리가 안 돼 따로 둠 (PM 결정 · PD S 의견으로 닉네임 포함)

**진입** 상단 알림 아이콘 · 푸시

**동작**
1. 이벤트가 생기면 대상자에게 푸시를 보낸다. 앱 안 알림 목록에는 교환 요청 · 약속 취소 · 교환 확인만 저장한다 (종류 · 받는 사람 · 표시 항목 · 이동 화면은 정책서 P-07-04 표)
2. 푸시는 두 줄: 제목 = 상대방 닉네임(탈퇴했으면 "탈퇴한 사용자"), 내용 = 알림 종류별 문장 + 교환글 제품명. 메시지 내용은 넣지 않는다. 문장은 PD 작성
3. 알림 목록: 최신순 20개씩, 안 읽은 알림 강조, 아이콘에 안 읽은 수 배지
4. 알림을 누르면 읽음 처리 후 해당 화면으로 이동
5. [모두 읽음]으로 전체 읽음 처리

**1차 푸시 4종** 교환 요청 · 새 메시지 · 약속 취소 · 교환 확인
- 새 메시지 = 채팅 메시지 · 글 · 아이템 수정 · 교환글 삭제 · 첨부 아이템 삭제 · 약속 제안 · 확정 · 거절 · 약속 제안 자동 취소 · 약속 다시 잡기 가능 (9가지 상황이 같은 문장)
- 약속 취소 = + 메뉴 취소 · 확정 약속이 있는 방 나가기 · [못 만났어요] · 차단 · 탈퇴 (이용 제한은 2차)
**1차 알림 목록** 교환 요청 · 약속 취소 · 교환 확인 3가지만. 채팅 메시지는 채팅 목록의 안 읽은 수로 확인
**2차** 새 메시지 9가지 중 채팅 메시지를 뺀 8가지를 상황별 문장으로 나누고 알림 목록에도 저장 · 새로 추가: 약속 전 알림 · 약속 변경 제안 · 약속 제안 만료 · 리마인드 · 자동 완료 하루 전 · 자동 완료 · 후기 요청 · 지금 교환 반복 · 키워드 · 운영 안내

**운영 안내 알림** 운영자가 관리자 페이지(H)에서 나에 대해 무언가를 처리하면 오는 알림. 알림별로 누르면 가는 곳:

| 알림 | 이동 |
|---|---|
| 글이 삭제됐어요 | 내 교환글 (5-04) |
| 경고를 받았어요 · 이용이 제한됐어요 · 노쇼로 기록됐어요 | 내 프로필 (5-02, 이용 상태 · 노쇼 기록) |
| 경고가 취소됐어요 · 노쇼 기록이 취소됐어요 · 이용 제한이 해제됐어요 | 내 프로필 (5-02) |
| 교환 전으로 되돌렸어요 (자동 완료를 운영자가 되돌림) | 그 채팅방 (2-02) |

**조건**
- 보관 기간 30일
- 알림 종류별 설정은 G-06-1 (2차). 운영 안내 알림은 끌 수 없다 (꼭 알아야 하는 안내)
- 수락 · 거절 · 재요청 알림 없음 (10/19 요청 단계 삭제)
- 그 채팅방을 열어 보고 있는 동안에는 그 방의 푸시를 띄우지 않는다
- 메시지가 연달아 오면 메시지마다 바로 보낸다 (합치지 않음)
- 차단 관계에는 알림을 보내지 않는다. 예외: 차단으로 확정 약속이 취소될 때는 약속 취소 푸시를 보낸다 (다른 취소와 같은 문장이라 차단 사실은 알 수 없음)
- 알림을 끈 채팅방은 그 방의 푸시를 모두 보내지 않는다 (E-09-1)

| 예외 상황 | 처리 |
|---|---|
| 0건 | "아직 받은 알림이 없어요" |
| 대상 글 · 채팅방이 삭제됨 | "삭제되었거나 볼 수 없는 글이에요", 알림은 읽음 처리 |
| 불러오기 실패 | 공통 오류 (P-07-03) |

### X-02-1 이미지 크게 보기

> 사진을 누르면 검은 배경 전체 화면으로 크게 보고, 좌우로 넘겨 다른 사진을 본다

| 상태 | MVP | 배포 | 우선순위 | 요구사항 | 정책 | 화면 |
|---|---|---|---|---|---|---|
| 확정 | 포함 | 2차 | P1 | REQ-C-05 | - | 9-06 |

- **예외 · 제약:** 교환글 상세 · 요청 아이템 상세 · 채팅 사진 공통 · 핀치 줌 없음
- **비고:** v0.4 (10/26) 새 기능

**진입** 교환글 상세 · 요청 아이템 상세 · 채팅의 사진을 누름

**동작**
1. 검은 배경 전체 화면, 위 왼쪽 [X], 아래 "1 / n"
2. 이미지는 화면 가운데, 좌우를 꽉 채우고 위아래 남는 곳은 검은 배경 (세로 · 정사각형 · 가로 사진 모두 잘리지 않음, PD 시안 3종)
3. 좌우로 넘겨 같은 글 · 아이템의 다른 사진을 본다
4. [X] → 원래 화면

**조건**
- 사진이 1장이면 "1 / n" 표시 없음
- 핀치 줌은 넣지 않음 (PD 안, 10/26)
- 굿즈 사진(3:4 · 9:16)은 잘리지 않는다. 화면보다 세로로 긴 이미지(긴 캡처)도 자르지 않고 화면 높이에 맞춰 전체가 보이게 줄인다. 양옆은 검은 여백 (10/31)

| 예외 상황 | 처리 |
|---|---|
| 이미지 불러오기 실패 | 회색 자리 + "사진을 불러올 수 없어요" |

**결과** 사진을 크게 표시
