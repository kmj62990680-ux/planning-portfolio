## 기능 명세 · 정책 · 2026-11-17 (사진 업로드 · 교환 장소 · 곧 만료 배지)

- **지금 교환 배지(B-04-1 · C-02-1):** "지금 교환 · n분" → "지금교환"(칩이 길어져 분 표시 뺌). 끝나기 10분 전부터 빨간 "곧 만료" 배지. 순서 = 곧 만료 · 지금교환
- **예약중 글 목록에서 빼기(C-02-1):** 예약중이면 교환 요청을 받을 수 없어 홈 목록에서 빼고, 약속이 취소되면 다시 보임. 예약중 표시는 상세 · 내 교환글 · 채팅 상단에만
- **홈 빈 화면 · 카드(C-02-1):** 일반 교환 0개 빈 화면 추가, 빈 화면 보조 문구 · 공통 오류 문구, 원하는 아이템 최대 2줄 · "아무거나" 표시, 카드 ⋮ 내 글은 1차 수정 · 삭제만
- **홈 칩 · 정렬(C-02-2 · C-02-3):** 칩은 하나만 선택(최신 ▾ · 지금 교환 · 일반 교환 · 캐릭터 · 아이돌 · 스포츠 · 기타). 첫 칩 = 전체 + 정렬, 다른 칩은 최신순 고정. 인기순 · 가까운순(내 위치 기준)을 2차 → 1차로
- **1차 홈 헤더(C-02-1):** "모든 지역"(▾ 없음) · 알림만. 지역 설정(C-01-1) · 검색(C-03-1)은 2차 그대로, 화면에서 숨김

- **사진 순서(B-01-2):** 카메라 칸 옆(가장 왼쪽)부터 오른쪽으로 한 장씩 추가, 가장 왼쪽 사진이 대표 사진이고 "대표" 표시
- **사진 칸 동작(B-01-2):** 바텀시트 [앨범 / 카메라]로 확정. 새 글 첫 진입 때만 바로 열고, 수정 · 뒤로 돌아올 땐 열지 않음. 시트 안내 문구는 PD 확인 중
- **교환 장소(B-03-1 · B-03-2):** PD 흐름대로 교환 장소 화면 → 지도 화면(검색창 · 거점 칩 · 핀 · [장소 선택하기]) → 검색 화면. 검색 결과를 고르면 지도 없이 장소 설정 칸에 바로 들어감. 거점 칩은 지도 이동만
- **표기(P-03-04):** 지도 하단 1줄 지번 · 2줄 도로명, 장소 설정 칸은 상세와 같게(검색 = 장소 이름 / 핀 = 구 + 동 + 번지)
- **상세 주소:** "만날 곳 이름" → "상세 주소", 최대 30자 유지. 1자 입력은 오류 없이 목록만 안 보여줌. 장소 미선택 오류 "교환 장소를 선택해주세요."(B-06-1). 결과 없음 문구는 PD 확인 중
