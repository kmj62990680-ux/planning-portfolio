## 원본에서 바꾼 것

- **우선순위:** 문자 진입(FR-11)은 P1 → P0, 위치 없이 최소 안내(FR-14)는 P2 → P0. 둘 다 7/30 데모에서 동작했다.
- **삭제:** 타는 곳 미확정 대기 화면(FR-12, E3). 문자가 타는 곳 확정 뒤에 가므로 이 상태가 생기지 않는다(원본 테스트케이스 최종본에서도 제외).
- **화면 ID:** 요구사항정의서(6월)의 S1~S6 · E1~E4 대신 화면설계서(7월)의 S0 · S1 · S1-1 · S2 · S2-1 · S3 · S4 · S5 · S6을 쓴다. 정적 안내는 E1, 변경 재안내는 E2로 다시 붙였다.
- **번호:** 원본 FR은 문서 안 순서가 섞여 있었다(FR-03이 맨 앞, FR-16이 FR-13과 14 사이). REQ는 사용자 흐름 순서로 매기고, 원본 FR 번호는 대조용으로 남긴다.
