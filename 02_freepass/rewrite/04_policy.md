# 04. 정책 (규칙 · 기준값)

> 재정리본 v1.0 (2026-11-18). 원본에는 정책서가 따로 없었고, 기준값이 화면설계서 9장의 화면별 "정책 기술"과 요구사항정의서 · 텍스트라이팅 가이드에 흩어져 있었다. 여기 한 곳에 모으고, 문서끼리 다르던 값은 아래 "통일한 값"에 적었다.

## P-01 문자 발송

| 항목 | 기준 |
|---|---|
| 발송 시점 | 타는 곳 확정 시점(출발 약 15분 전) |
| 횟수 | 1회, 재발송 없음 |
| 발신 | 코레일 공식 발신번호만 |
| 링크 | 단축 URL을 쓰지 않는다. 공식 도메인을 그대로 보여 스미싱으로 오인하지 않게 한다 |
| 문구 | 3줄 이내, 존댓말, 한 문장 25자 이내 |
| 필수 항목 | [Web발신] 표기 · 구간 · 열차번호 · 출발 시각 · 시작 링크 |
| 안심 문자(P2) | 확정 전 "정시 운행 중 · 곧 안내", 기본 꺼짐 |

이 서비스에서 가장 많이 떠나는 지점은 링크를 누르기 전이다. 발신번호 사전 등록과 도메인 노출이 화면 개선보다 시작률에 크게 작용한다.

## P-02 링크 토큰 · 승차권

| 항목 | 기준 |
|---|---|
| 인증 | 문자 링크 토큰으로 승차권 정보를 채운다. 별도 로그인 · 본인인증 없음 |
| 유효기간 | 출발 시각 + 30분 |
| 만료 | 다른 모든 검증보다 먼저 막는다 |
| 마스킹 | 승차권번호는 뒤 4자리만 보인다 |
| 첫 화면 | S1은 네트워크 요청 없이 바로 그리고, 조회 지연은 S1-1 로딩 상태로 흡수한다 |

## P-03 위치 · 측위

| 항목 | 기준 |
|---|---|
| 권한 요청 | 2단: 우리 화면의 사전 설명 → 브라우저 권한 팝업 |
| 거부 | 서비스를 끝내지 않고 E1 정적 안내 |
| 시작 검증 순서 | 토큰 유효 → 위치 권한 → 측위 신뢰도 |
| 측위 실패 | 3회 연속이면 안내를 멈추고 E1로 넘어간다 |
| 좌표 튐 | 직전 안내를 유지하고 문구를 바꾸지 않는다 |
| 갱신 지연 | 마지막 좌표 기준 유지 |

## P-04 층

| 항목 | 기준 |
|---|---|
| 제천역 구조 | 시작 층 = **3층 맞이방**, 승강장 = **1층** |
| 층 판정 | 측위로 층을 확정하지 않는다. 사용자에게 묻는다(S3) |
| 목표 층 | 승차권의 승강장 정보로 역별 고정 데이터에서 가져온다. 사용자에게 층 번호를 묻지 않는다 |
| 왕복 제한 | S3 ↔ S2-1 왕복이 2회를 넘으면 층 확인을 건너뛰고 S4로 진행, 부정확할 수 있다고 화면에 알린다 |

## P-05 경로 안내

| 항목 | 기준 |
|---|---|
| 경로 | 역 안을 노드 그래프로 두고 현재 노드 → 목적지 노드 최단 경로 |
| 화면 상태 | 직진 / 좌 · 우회전 / 계단 · 에스컬레이터 · 엘리베이터 / 승강장 진입 (화면 하나, 상태 넷) |
| 남은 거리 | 다음 분기점까지, 1m 단위 반올림, 3초마다 갱신 |
| 안내 문구 | 상태가 바뀔 때 음성과 함께. 2줄 · 20자 이내 |
| 방향 표현 | 방위 · 거리 대신 눈에 보이는 랜드마크("매점에서 오른쪽") |
| 재경로(P2) | 떨어진 타는 곳으로 바뀌면 층 이동을 포함한 경로를 불러온다 |

경로 데이터(노드 좌표 · 거리)는 코레일 내부자료를 바탕으로 만들어 공개하지 않는다.

## P-06 도착

| 항목 | 기준 |
|---|---|
| 판정 | 목적지 노드 반경 5m 안 |
| 피드백 | 화면 변화 + 음성 + 진동 동시. 음성을 꺼 둘 수 없으므로 항상 함께 난다 |
| 종료 | 자동으로 닫지 않는다. 사용자가 직접 끝낸다 |

## P-07 호차

| 항목 | 기준 |
|---|---|
| 기본값 | 승차권의 호차 |
| 변경 | 가능(동행자와 좌석이 떨어진 경우). 승차권 호차와 다르면 확인 팝업 |
| 없음 | 타는 곳까지만 안내 |

## P-08 시간 (P1)

| 항목 | 기준 |
|---|---|
| 임박 | 출발 5분 전부터 강조. 색 · 아이콘 · 문구를 함께 바꾼다(색만으로 전하지 않음) |
| 만료 | 출발 시각이 지나면 "출발 시간이 지났어요. 안내를 종료할게요." |

## P-09 음성 · 접근성

| 항목 | 기준 |
|---|---|
| 음성 | 모든 화면에서 자동 재생, 단계가 바뀔 때마다 자동 안내. 켜고 끄는 버튼 없음 |
| 글자 | 본문 18sp 이상, 핵심 안내 24sp 이상 |
| 대비 | 4.5:1 이상 |
| 터치 | 48×48dp 이상, 화면당 주요 행동 1개 |
| 장식 | 일러스트는 스크린리더에서 건너뛴다 |

## P-10 용어

| 쓰지 않음 | 화면 · 음성 표기 |
|---|---|
| 고상홈 | 높은 승강장 |
| 저상홈 | 낮은 승강장 |
| 플랫폼 · 승강장 번호 | O번 타는 곳 |
| 객차 | O호차 |

화면 · 음성 표기는 현장 표지판과 같게 맞춘다. 자세한 문구는 [06 텍스트라이팅](06_text-writing.md).

## 통일한 값 (원본 문서끼리 달랐던 것)

| 항목 | 원본에서 어긋난 곳 | 재정리본 |
|---|---|---|
| 층 | 요구사항정의서 · 화면설계서 "2층에 계신가요?" / 테스트케이스 · 텍스트라이팅 "3층 맞이방 · 1층 승강장" | 3층 맞이방 · 1층 승강장 (현장 기준) |
| 음성 | 화면설계서 "음성안내 토글 기본 ON, 끌 수 있음" / 요구사항 · 텍스트라이팅 · 테스트케이스 "버튼 없이 상시 재생" | 상시 재생, 버튼 없음 (텍스트라이팅 최종본) |
| 본문 글자 | 화면설계서 S1-1 "최소 15sp" / 요구사항 "18sp 이상" | 18sp 이상 |
| 승강장 용어 | 요구사항 "유리문 있는 곳 / 낮은 곳" / 텍스트라이팅 "높은 · 낮은 승강장(표지판)" | 높은 · 낮은 승강장. "유리문" 병기는 원본에서 결정하지 못한 채 끝났다 |
| 위치 거부 | 요구사항 E1 정적 안내 / 화면설계서 S2-1 층 이동 안내로 분기 | 권한 거부 → E1, 층이 아닐 때 → S2-1로 나눔 |
| 우선순위 | 문자 진입 · 위치 거부 안내 · 타는 곳 변경이 요구사항(P1 · P2)과 테스트케이스(상)에서 다름 | 7/30 데모 기준: 앞의 둘은 P0, 변경은 P2 |
