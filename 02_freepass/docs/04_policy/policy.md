## 규칙

- **정책 ID** = 분류 번호 + 순번 (예: P-01-02)
- **분류:** P-01 문자 · 링크 / P-02 위치 · 층 / P-03 안내 · 도착 / P-04 시간 / P-05 음성 · 접근성 · 용어
- **상태:** 확정 / 논의
- 화면 동작은 기능 명세서에 두고, 정책서에는 기준값 · 규칙만 둔다

## P-01 문자 · 링크

### P-01-01 문자 발송

| 항목 | 기준 |
|---|---|
| 발송 시점 | 타는 곳 확정 시점 (출발 약 15분 전) |
| 횟수 | 1회, 재발송 없음 |
| 발신 | 코레일 공식 발신번호만 |
| 링크 | 단축 URL 금지, 공식 도메인 그대로 |
| 문구 | 3줄 이내, 존댓말, 한 문장 25자 이내 |
| 필수 항목 | [Web발신] · 구간 · 열차번호 · 출발 시각 · 시작 링크 |
| 안심 문자 (P2) | 확정 전 "정시 운행 중 · 곧 안내", 기본 꺼짐 |

- 근거: 이 서비스에서 가장 많이 떠나는 지점은 링크를 누르기 전이다. 고령 사용자일수록 모르는 링크를 누르지 않는다. 발신번호 사전 등록과 도메인 노출이 화면 개선보다 시작률에 크게 작용한다
- 기능: A-01-1

### P-01-02 링크 토큰 · 승차권

| 항목 | 기준 |
|---|---|
| 인증 | 링크 토큰으로 승차권 정보를 채움. 로그인 · 본인인증 없음 |
| 유효기간 | 출발 시각 + 30분 |
| 만료 | 다른 모든 검증보다 먼저 막음 |
| 마스킹 | 승차권번호는 뒤 4자리만 노출 |
| 첫 화면 | S1은 네트워크 요청 없이 즉시 렌더, 조회 지연은 S1-1 로딩으로 흡수 |

- 기능: A-02-1 · A-03-1

## P-02 위치 · 층

### P-02-01 위치 권한

| 항목 | 기준 |
|---|---|
| 요청 | 2단: 우리 화면 사전 설명 → 브라우저 권한 팝업 |
| 표시 | 권한 획득 전에는 내 위치 마커를 표시하지 않음 |
| 거부 | 서비스를 끝내지 않고 E1 위치 없이 최소 안내 |

- 기능: B-01-1 · B-04-1

### P-02-02 측위

| 항목 | 기준 |
|---|---|
| 시작 검증 순서 | 승차권 토큰 유효 → 위치 권한 → 측위 신뢰도 |
| 실패 | 3회 연속이면 안내를 멈추고 E1로 폴백 |
| 좌표 튐 | 직전 안내 유지, 문구 변경 없음 |
| 갱신 지연 | 마지막 좌표 기준 유지 |

- 근거: 실내는 GPS 정확도가 낮다. 잘못된 화살표는 안내가 없는 것보다 위험하다
- 기능: A-03-1 · B-04-1 · C-02-1

### P-02-03 층

| 항목 | 기준 |
|---|---|
| 제천역 구조 | 시작 층 = 3층 맞이방, 승강장 = 1층 |
| 층 판정 | 측위로 확정하지 않고 사용자에게 확인 |
| 목표 층 | 승차권 승강장 정보 → 역별 고정 데이터. 사용자에게 층 번호를 묻지 않음 |
| 왕복 제한 | S3 ↔ S2-1 왕복 2회 초과 시 층 확인을 건너뛰고 S4로, 부정확할 수 있다고 화면에 알림 |

- 근거: GPS는 위경도만 주고 층(고도)은 실내에서 신뢰할 수 없다
- 기능: B-02-1 · B-03-1

## P-03 안내 · 도착

### P-03-01 경로 안내

| 항목 | 기준 |
|---|---|
| 경로 | 역 안 노드 그래프, 현재 노드 → 목적지 노드 최단 경로 |
| 화면 상태 | 직진 / 좌 · 우회전 / 계단 · 에스컬레이터 · 엘리베이터 / 승강장 진입 |
| 남은 거리 | 다음 분기점까지, 1m 단위 반올림, 3초마다 갱신 |
| 안내 문구 | 상태 전환 시 음성과 함께, 2줄 · 20자 이내 |
| 방향 표현 | 방위 · 거리 대신 랜드마크 |
| 재경로 (P2) | 떨어진 타는 곳으로 바뀌면 층 이동을 포함한 경로를 불러옴 |

- 경로 데이터(노드 좌표 · 거리)는 코레일 내부자료를 바탕으로 만들어 공개하지 않는다
- 기능: C-02-1 · C-03-1

### P-03-02 호차

| 항목 | 기준 |
|---|---|
| 기본값 | 승차권 호차 |
| 변경 | 가능. 승차권 호차와 다르면 확인 팝업 |
| 없음 | 타는 곳까지만 안내 |

- 기능: C-01-1

### P-03-03 도착

| 항목 | 기준 |
|---|---|
| 판정 | 목적지 노드 반경 5m 안 |
| 피드백 | 화면 변화 + 음성 + 진동 동시 |
| 종료 | 자동으로 닫지 않음, 사용자가 직접 종료 |

- 기능: D-01-1

## P-05 음성 · 접근성 · 용어

### P-05-01 음성

| 항목 | 기준 |
|---|---|
| 재생 | 모든 화면 자동 재생, 단계 전환마다 자동 안내 |
| 버튼 | 켜고 끄는 버튼 없음 |

- 기능: X-01-1

### P-05-02 접근성

| 항목 | 기준 |
|---|---|
| 글자 | 본문 18sp 이상, 핵심 안내 24sp 이상, 확대 가능 |
| 대비 | 4.5:1 이상, 색만으로 의미 전달 금지 |
| 터치 | 48×48dp 이상, 화면당 주요 행동 1개 |
| 장식 | 일러스트는 스크린리더에서 건너뜀 |

- 요구사항: REQ-N-01 ~ 03

### P-05-03 용어

| 쓰지 않음 | 화면 · 음성 표기 |
|---|---|
| 고상홈 | 높은 승강장 |
| 저상홈 | 낮은 승강장 |
| 플랫폼 · 승강장 번호 | O번 타는 곳 |
| 객차 | O호차 |

- 화면 · 음성 표기는 현장 표지판과 같게 맞춘다
- **논의 (원본에서 결정하지 못하고 끝남):** "유리문 있는 · 없는 곳" 병기 여부 · 발신명 "코레일 동행안내"와 화면 이름 "승강장 안내 서비스" 통일 여부
- 기능: X-02-1
