| 연결 | 요구사항마다 "기능"으로 기능 명세서 ID를 가리킴. 원본 FR 번호는 대조용으로 남김 |

## 규칙

- **ID:** `REQ-영역-번호`
  - A 진입 / B 위치 · 층 확인 / C 길찾기 / D 도착 / X 공통 / N 비기능
- **요구사항 문장:** "사용자는 \~할 수 있다" / "시스템은 \~해야 한다"
- **우선순위:** P0 = 7/30 데모에서 동작 / P1 = 여유 시 / P2 = 설계 · 기록만. [개요](../01_overview/overview.md#우선순위-기준) 참고
- **상태:** 확정 / 논의 (원본에서 결정하지 못하고 끝남)
- **화면:** 원본 화면설계서의 화면 번호 (S0~S6). 원본에 없는 화면은 E1 · E2

## A 진입

### REQ-A-01
시스템은 타는 곳이 확정되면(출발 15분 전) 안내 링크가 담긴 문자를 1회 보내야 한다
- `P0` · 확정 · 기능 A-01-1 · 화면 S0 · 원본 FR-11
- 예외: 재발송 없음

### REQ-A-02
사용자는 문자 링크를 눌러 앱 설치 · 로그인 없이 바로 시작할 수 있다
- `P0` · 확정 · 기능 A-02-1 · 화면 S1 · 원본 FR-11

### REQ-A-03
시스템은 링크 토큰으로 승차권 정보를 채우고, 안내를 시작하기 전에 승차권 · 위치 권한 · 측위를 검증해야 한다
- `P0` · 확정 · 기능 A-03-1 · 화면 S1-1
- 예외: 만료된 승차권(출발 시각 + 30분)은 다른 검증보다 먼저 막음

## B 위치 · 층 확인

### REQ-B-01
사용자는 위치가 왜 필요한지 설명을 보고 위치 권한을 줄 수 있다
- `P0` · 확정 · 기능 B-01-1 · 화면 S2
- 예외: 거부해도 서비스는 끝나지 않음 (REQ-B-04)

### REQ-B-02
사용자는 자신이 시작 층(3층 맞이방)에 있는지 확인할 수 있다
- `P0` · 확정 · 기능 B-02-1 · 화면 S3 · 원본 FR-01

### REQ-B-03
사용자는 시작 층이 아니면 시작 층으로 오는 길을 안내받을 수 있다
- `P0` · 확정 · 기능 B-03-1 · 화면 S2-1 · 원본 FR-01

### REQ-B-04
사용자는 위치를 쓸 수 없어도 타는 곳 · 호차 · 승강장을 글자와 음성으로 안내받을 수 있다
- `P0` · 확정 · 기능 B-04-1 · 화면 E1 · 원본 FR-14
- 비고: 원본 P2 → P0 (7/30 데모에서 동작)

## C 길찾기

### REQ-C-01
사용자는 승차권의 타는 곳 · 호차를 확인하고 길찾기를 시작할 수 있다
- `P0` · 확정 · 기능 C-01-1 · 화면 S4 · 원본 FR-02
- 예외: 타는 곳은 바꿀 수 없음, 호차는 바꿀 수 있음

### REQ-C-02
사용자는 화살표 · 남은 거리 · 단계 문구로 높은 · 낮은 승강장과 호차 위치까지 안내받을 수 있다
- `P0` · 확정 · 기능 C-02-1 · 화면 S5 · 원본 FR-03 · FR-04 · FR-05 · FR-06

### REQ-C-03
사용자는 지연 · 타는 곳 변경을 알림받고 층 이동을 포함한 새 경로로 다시 안내받을 수 있다
- `P2` · 확정 · 기능 C-03-1 · 화면 E2 · 원본 FR-13 · FR-16
- 비고: 설계만, 7/30 데모 미구현

## D 도착

### REQ-D-01
사용자는 목적지 호차 앞에 도착하면 화면 · 음성 · 진동으로 알림받고 직접 안내를 끝낼 수 있다
- `P0` · 확정 · 기능 D-01-1 · 화면 S6 · 원본 FR-09

## X 공통

### REQ-X-01
시스템은 모든 안내를 음성으로 상시 자동 재생해야 한다
- `P0` · 확정 · 기능 X-01-1 · 화면 전체 · 원본 FR-07

### REQ-X-02
시스템은 화면 · 음성 어디에도 전문용어를 쓰지 않아야 한다
- `P0` · 확정 · 기능 X-02-1 · 화면 전체 · 원본 FR-08

### REQ-X-03
사용자는 출발 임박(5분 전)을 강조해서 볼 수 있고, 출발 시각이 지나면 안내가 끝난다
- `P1` · 확정 · 기능 X-03-1 · 화면 S5 · 원본 FR-10

### REQ-X-04
시스템은 확정 전 안심 문자를 선택으로 보낼 수 있다 (기본 끔)
- `P2` · 확정 · 기능 없음(정책 P-01-01만) · 원본 FR-15

## N 비기능

### REQ-N-01
글자는 본문 18sp 이상, 핵심 안내 24sp 이상이고 확대할 수 있어야 한다
- `P0` · 확정 · 정책 P-05-02

### REQ-N-02
대비는 4.5:1 이상이고, 색만으로 의미를 전하지 않는다 (아이콘 · 글자 함께)
- `P0` · 확정 · 정책 P-05-02

### REQ-N-03
주요 버튼은 48×48dp 이상이고, 화면당 주요 행동은 1개다
- `P0` · 확정 · 정책 P-05-02

### REQ-N-04
첫 화면(S1)은 네트워크 요청 없이 바로 그린다
- `P0` · 확정 · 정책 P-01-02

### REQ-N-05
설치 없는 모바일 웹으로 제공한다
- `P0` · 확정
