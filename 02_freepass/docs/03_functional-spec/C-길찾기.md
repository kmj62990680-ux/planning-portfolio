### C-01-1 탑승 정보 확인

> 승차권의 타는 곳 · 호차로 목적지를 확정하고 길찾기를 시작한다

| 상태 | 우선순위 | 요구사항 | 정책 | 화면 | 테스트 |
|---|---|---|---|---|---|
| 확정 | P0 | REQ-C-01 | P-03-02 | S4 | A-04 · D-04 |

**진입** S3 [네] (B-02-1), 또는 S1-1 검증 통과 (A-03-1)

**동작**
1. 타는 곳 번호를 크게 보여 준다
2. 호차를 고른다 (승차권 호차가 기본 선택)
3. [길찾기 시작]을 누르면 현재 노드 → 목적지 노드(승강장 정차 위치) 최단 경로를 찾는다

**조건**
- 타는 곳은 승차권 값이라 읽기 전용
- 호차를 바꿀 수 있게 열어 둔 이유: 동행자와 좌석이 떨어진 경우

| 예외 상황 | 처리 |
|---|---|
| 승차권과 다른 호차를 고름 | 확인 팝업. 바뀐 호차로 안내하면 본인 좌석과 다른 문을 열게 된다 |
| 호차 정보 없음 | 타는 곳까지만 안내 (D-04) |

**결과** S5 (C-02-1)

### C-02-1 경로 안내

> 화살표 · 남은 거리 · 단계 문구 · 음성으로 높은 · 낮은 승강장과 호차 위치까지 안내한다

| 상태 | 우선순위 | 요구사항 | 정책 | 화면 | 테스트 |
|---|---|---|---|---|---|
| 확정 | P0 | REQ-C-02 | P-03-01 · P-02-02 | S5 | A-05 ~ A-14 · B-03 ~ B-07 · C-04 · E-01 ~ E-09 · G-02 ~ G-08 · H-03 |

**진입** S4 [길찾기 시작] (C-01-1)

**동작**
1. 화면 하나에서 상태 넷을 바꿔 가며 보여 준다: 직진 / 좌 · 우회전 / 계단 · 에스컬레이터 · 엘리베이터 / 승강장 진입
2. 상태가 바뀔 때마다 화살표 + 단계 문구 + 음성을 함께 낸다
3. 승강장에 들어서면 높은 · 낮은 승강장을 구분하고 호차 위치를 안내한다

**조건**
- 남은 거리는 다음 분기점까지
- 상단 정보바(출발 시각 · 타는 곳 · 호차 · 좌석)는 S4~S6에서 고정
- 방향은 랜드마크 기준 ("{가게}에서 오른쪽으로 도세요")

| 예외 상황 | 처리 |
|---|---|
| 측위 실패 3회 연속 | 안내를 멈추고 E1 (B-04-1). 잘못된 화살표는 안내가 없는 것보다 위험하다 |
| GPS 약함 · 끊김 | "잠시만요, 지금 계신 곳을 확인하고 있어요." (B-03) |
| 좌표 튐 · 갱신 지연 | 직전 안내 · 마지막 좌표 유지 (B-04 · B-07) |
| 방향센서 없음 · 오작동 | "화살표 대신 글과 음성으로 안내할게요." (B-05) |
| 측위 오차 큼 | "가까운 곳까지 왔어요. 주변을 살펴봐 주세요." (B-06) |
| 다른 출입구로 진입 | "다른 입구예요. 화살표를 확인해주세요." (C-04) |
| 경로 이탈 · 반대편 승강장 · 지나침 | 재안내 문구 (E-01 · E-02 · E-07 · E-08) |
| 엘리베이터 안 신호 끊김 | "엘리베이터에서 내리면 이어서 안내할게요." (E-05) |
| 계단 · 에스컬레이터 · 통로에서 멈춤 | 직전 안내 유지 또는 기다림 문구 (E-03 · E-04 · E-06) |
| 잘못된 승강장 도착 | "여기가 아니에요. O번 타는 곳으로 안내할게요." (H-03) |
| 네트워크 끊김 · 재접속 · 새로고침 | 다시 연결 중 안내, 진행 지점 유지 (G-02 ~ G-05) |

**결과** 도착 판정 반경에 들어오면 S6 (D-01-1)

### C-03-1 지연 · 타는 곳 변경 재안내

> 지연 · 타는 곳 변경을 알리고 층 이동을 포함한 새 경로로 다시 안내한다

| 상태 | 우선순위 | 요구사항 | 정책 | 화면 | 테스트 |
|---|---|---|---|---|---|
| 확정 | P2 | REQ-C-03 | P-03-01 | E2 | D-01 · D-02 · D-03 |

**진입** S5 진행 중 또는 도착 후 지연 · 변경 이벤트

**동작**
1. 화면 전환이 아니라 팝업 + 음성으로 알린다 ("타는 곳이 바뀌었어요.")
2. S5 경로를 새로 그린다

**조건**
- 떨어진 타는 곳으로 바뀌면 층 이동을 포함해 안내한다 (엘리베이터로 3층 → 목표 승강장)
- 모든 승강장 사이 이동 경로를 미리 데이터로 가지고 있어야 한다

**결과** S5 재안내

**비고** 설계만, 7/30 데모 미구현
