## 다섯 원칙

1. **짧게:** 한 화면 3줄 이내, 한 문장에 행동 하나.
2. **쉽게:** 전문용어 금지. "고상홈 · 저상홈", "플랫폼"을 쓰지 않는다.
3. **눈에 보이는 것 기준:** 방위 · 거리 대신 랜드마크. "북쪽 30m" 대신 "편의점에서 오른쪽".
4. **행동형 어미:** "~하세요 / ~해 주세요 / ~할게요"로 끝낸다. 설명은 줄인다.
5. **안심 톤:** 문제 상황에서도 재촉 · 경고 대신 "잠시만요 / 이어서 안내할게요".

## 용어

화면 · 음성 표기는 **현장 표지판과 같게** 맞춘다. 어르신이 표지판을 보고 그대로 따라올 수 있어야 한다.

| 표지판 · 전문용어 | 서비스 표기 |
|---|---|
| 고상홈 | 높은 승강장 |
| 저상홈 | 낮은 승강장 |
| 플랫폼 · 승강장 번호 | {번호}번 타는 곳 |
| 객차 번호 | {호차}호차 |

## 문자 문구 (S0)

```
[Web발신]
코레일 동행안내
(서울역 ▶ 제천역)
[KTX 1063]
출발시각: 7시 25분

안녕하세요.
예매하신 열차가 15분 뒤에 출발해요.
지금 계신 곳에서 타는 곳까지 안내해 드릴게요.

▶ 안내 시작하기
(공식 도메인 링크)
```

## 원본의 "확인 · 결정 필요" 정리

| 원본 항목 | 재정리본 |
|---|---|
| 층 표기(3층 맞이방 / 1층 승강장)를 화면 · 요구사항과 통일 | 통일함 (정책 P-02-03) |
| 요구사항정의서 단어집을 "높은 · 낮은 승강장"으로 동기화 | 통일함 (정책 P-05-03) |
| "유리문 있는 · 없는 곳" 병기 여부 | 원본에서 결정하지 못하고 끝남. 표지판 표기만 쓴다 |
| 발신명 "코레일 동행안내"와 화면 이름 "승강장 안내 서비스"가 둘 | 원본에서 결정하지 못하고 끝남 |
| {가게} 실제 상호 | 현장 확인 항목. 공개본에서는 변수로 둔다 |
