## 이 폴더의 두 가지

| 폴더 | 내용 | 시점 |
|---|---|---|
| [original/](original/) | 프로젝트 기간에 쓴 **원본** 그대로 (PDF) | 2026.06 ~ 07 |
| [rewrite/](rewrite/) | 원본을 바꾸 프로젝트에서 만든 방식으로 다시 정리한 **재정리본** (md) | 2026.11 |

**재정리본은 프로젝트가 끝난 뒤에 다시 정리한 문서입니다.** 원본을 프로젝트 기간에 이 형태로 쓴 것은 아닙니다. 원본은 문서 하나하나는 갖췄지만 문서끼리 층 표기 · 우선순위 · 음성 정책이 어긋나 있었습니다. 이후 [바꾸](../01_bakku/)에서 원본 하나 · ID 연결 · 정책서 분리 · 변경 기록으로 이 문제를 풀었고, 같은 방식을 프리패스에 거꾸로 적용한 것이 재정리본입니다. 무엇을 고쳤는지는 [rewrite/CHANGELOG](rewrite/CHANGELOG.md)에 있습니다.

## 공개하지 않는 자료

다음은 **코레일 내부자료라 공개할 수 없습니다.**

- 민원(VOC) 자료
- 역 도면 · 피난안내도, 이를 바탕으로 만든 경로 노드 좌표 · 거리 수치
