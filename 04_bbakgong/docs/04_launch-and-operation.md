# 04 출시와 운영

## 1. 출시

- 2026.11.26 첫 검토 요청, 승인 후 출시
- 검토 대상이던 주요 기능 3개, 결과 화면 문구 모두 그대로 통과

## 2. 지표 설계

| 구분 | 지표 | 이유 |
|---|---|---|
| 활성 | 7일 이후 재방문 | 오답을 다시 풀러 돌아오는지 본다 |
| 대표 전환 | 문제 5개를 다 푼 사용자 | 채점과 해설까지 받아야 가치를 얻는다 |
| 품질 | "이 문제 이상해요" 신고 비율 | AI 문제의 정확도를 운영 중에도 잰다 |

- 흐름: 사진 → 문제 생성 → 다 풀기 → 오답 다시 풀기 → 인증 카드
- 비용: 1회 비용과 월 예산 사용률을 함께 본다.
