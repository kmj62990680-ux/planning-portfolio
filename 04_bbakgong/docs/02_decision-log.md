# 02 결정 기록

결정마다 **사용자의 문제 → 결정 → 이유** 순서로 적는다.

## D-01 답 대신 문제를 준다

- **문제:** 사진을 찍으면 답을 주는 서비스는 이미 많지만, 답을 받은 공부는 시험장에서 남지 않는다.
- **결정:** 공부 자료로 새 문제를 낸다. 문제를 풀어 주는 기능은 넣지 않는다.
- **이유:** 이것이 차별점이다. 풀이 기능은 과제 · 시험 부정행위 도구로 쓰일 위험도 있다. 대신 다음 단계에서 "내 답을 먼저 쓰면 해설과 비슷한 문제"를 준다.

## D-02 모델은 정확도로 고른다

- **문제:** 정답이 틀린 문제 하나로 서비스 신뢰가 깨진다.
- **결정:** 4개 모델을 같은 자료로 비교하고, **정답 오류 0에 가까운 모델 중 가장 싼 것**을 고른다.
- **검증:** 올해 수능 11과목과 실제 수험생의 세법 교재 사진 21장, 모델마다 약 105문제

| 모델 | 정답 오류 | 품질 (5점) | 1회 비용 |
|---|---|---|---|
| Haiku 5.5 | 2 | 2.85 | 약 4원 |
| Sonnet 5.5 | 6 | 2.87 | 약 37원 |
| **Opus 5.5** | **1** | **3.58** | 약 103원 |
| Fable 5.2 | 0 | 3.27 | 약 187원 |

- **결과:** 가장 싼 Haiku로 시작하려 했지만 오류 기준을 넘지 못했다. Opus 5.5로 정하고, 문제 지시문을 다듬은 최종판에서 **정답 오류 0 / 105**를 확인했다.

## D-03 난이도는 두 단계, 기본은 "빡공"

- **문제:** AI가 내는 문제는 쉬운 확인 문제로 쏠린다.
- **결정:** "가볍게 / 빡공" 두 단계로 두고 기본값을 빡공으로 한다.
- **이유:** 빡공 난이도가 품질(3.54)과 해설(4.51) 모두 높고 정답 오류도 0이었다. 단계를 더 늘리면 결과 차이는 작고 고르기만 번거롭다.

## D-04 문제 유형은 고를 수 있게, 서술형은 제외

- **문제:** 시험 형식에 맞춰 연습하고 싶다.
- **결정:** 섞어서 / 객관식 / OX / 단답 중 고른다. 서술형은 넣지 않는다.
- **이유:** 유형별로 다시 검증해 정답 오류 0 / 105를 확인했다. 서술형은 채점을 AI가 한 번 더 해야 해서 비용과 오채점 위험이 크다.

## D-05 무료로 쓰되 비용은 예산으로 막는다

- **문제:** 사용자는 무료로 써야 하지만, 문제 1회에 약 100~150원이 든다.
- **결정:** 1인 횟수 제한은 두지 않고, **월 예산 상한**을 둔다. 80%를 넘으면 저렴한 모델 + 검토 단계로 자동 전환하고, 100%면 다음 달에 다시 열린다고 안내한다.
- **이유:** 사용자가 적을 때 1인 제한은 불편만 만든다. 진짜 안전장치는 예산 천장이다. 한 사람이 하루 30번을 넘으면 운영자에게 알림이 온다.

## D-06 사진과 개인정보

- **문제:** 필기 사진에 이름 같은 개인정보가 찍힐 수 있다.
- **결정:** 사진은 문제를 만든 뒤 바로 버린다. 처음 쓸 때 AI 이용과 처리 방식을 알리고, 개인정보처리방침에 AI 처리 업체(미국)와 국외 이전 사항을 공개한다.
- **이유:** 개인정보 보호법상 서비스 이행에 필요한 국외 처리위탁은 처리방침 공개로 근거를 갖춘다. 생성형 AI 결과 표시는 앱인토스 정책이다.

## D-07 AI 구조: 한 번 부르기와 에이전트를 구분한다

- **문제:** 사진 한 장에서 문제를 받는 데 오래 기다리거나 비용이 커지면 안 된다.
- **결정:** 문제 만들기는 AI를 **한 번 부르는 구조**로 한다. 에이전트는 다음 단계 "시험 D-day 복습 코치"에 쓴다.
- **이유:** "사진 → 문제 5개"는 한 번에 끝나는 일이라 에이전트로 만들면 느리고 비싸다. 복습 코치는 오답을 묶고, 변형 문제를 만들고, 남은 날짜에 맞춰 계획을 짜고, 결과를 보고 계획을 고치는 여러 단계라 에이전트가 맞다.

## D-08 대표 지표는 "문제를 다 푼 사용자"

- **기준:** 사용자가 가치를 받는 순간은 문제를 끝까지 풀고 채점을 받을 때다.
- **결정:** 대표 전환 = 문제 5개를 다 푼 사용자. 활성 지표 = 7일 이후 재방문(오답 다시 풀기가 돌아올 이유).
- **품질 지표:** "이 문제 이상해요" 신고 비율
