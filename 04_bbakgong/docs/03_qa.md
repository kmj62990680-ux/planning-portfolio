# 03 QA

| 항목 | 내용 |
|---|---|
| 앱 자동 시험 | 23개 항목 통과 |
| 서버 시험 | 23가지 경우 통과 |
| 실제 기기 | 토스 앱에서 사진 → 문제 → 채점 → 오답노트 전 과정 확인 |
| 출시 전 점검 | 앱인토스 검수 체크리스트 대조, 고칠 것 0건 |
| AI 품질 | [결정 기록 D-02](02_decision-log.md) 참고 |

## 1. 앱

- 가장 작은 화면(320px)에서 가장 긴 실제 문제(문제 125자, 보기 70자)가 깨지지 않는다.
- 글자 11px 이상, 누르는 곳 40px 이상, 가로 넘침 없음
- 단답은 띄어쓰기가 달라도 정답 처리한다.
- 흐린 사진은 다시 찍기를 안내하고 횟수를 쓰지 않는다.
- 새로고침해도 기록과 오답노트가 남는다.

| 문제 | 사용자에게 생길 일 | 조치 |
|---|---|---|
| 작은 화면에서 긴 보기 아래 해설이 가려짐 | 답을 골라도 해설을 못 봄 | 답을 고르면 해설로 자동 이동 |

## 2. 서버

- 앱이 보낸 사용자 정보를 그대로 믿지 않고, 토스에 확인받은 뒤에만 문제를 만든다.
- 위조된 출입 정보, 허용되지 않은 곳에서 온 요청은 거절한다.
- 월 예산 80%에서 저렴한 모델로 전환, 100%에서 멈춤 안내가 동작한다.
- 문제가 5개를 넘거나 응답이 잘리면 다시 처리한다.

## 3. 출시 전 점검

- 앱인토스 비게임 검수 체크리스트 원문과 대조했다.
- 출시 파일에 디버그 도구, 시험용 가짜 문제가 없는 것을 확인했다.
- 사용 연령 정책(만 19세 이상)을 공식 문서로 확인하고, 대상과 개인정보처리방침을 맞췄다.
