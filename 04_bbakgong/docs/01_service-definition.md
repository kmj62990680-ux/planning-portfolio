# 01 서비스 정의

## 1. 한 줄

오늘 공부한 자료를 찍으면, 그 내용으로 문제 5개를 내고 채점과 해설까지 해 준다.

## 2. 문제

- 공부한 내용을 확인하려면 문제가 필요하지만, 내 필기와 교재로 된 문제는 없다.
- 범용 AI로 퀴즈를 만들려면 요청을 직접 써야 하고, 틀린 문제를 모아 다시 풀기 어렵다.
- 사진을 찍으면 답을 주는 서비스는 많다. 하지만 시험장에는 직접 풀어 본 것만 남는다.

## 3. 대상

| 항목 | 내용 |
|---|---|
| 누구 | 대학생 시험기간, 공무원 · 자격증 수험생 |
| 원하는 것 | 오늘 공부한 것을 바로 확인하고, 틀린 것만 다시 풀기 |
| 불편한 것 | 문제집은 내 필기와 다르고, 오답 정리는 귀찮다 |

### 쓰는 순간

1. **공부를 마쳤을 때:** 필기나 교재를 찍으면 30~40초 뒤 문제 5개가 나온다.
2. **시험 전:** 오답노트에서 틀린 문제만 다시 푼다. 맞히면 오답노트에서 졸업한다.
3. **만점을 받았을 때:** "빡공냥이 인증" 카드를 저장해 공유한다.

## 4. 핵심 기능

| 기능 | 내용 |
|---|---|
| 사진으로 문제 만들기 | 사진 1~3장으로 문제 5개 |
| 난이도 | 가볍게 / 빡공 (기본 빡공) |
| 문제 유형 | 섞어서 / 객관식 / OX / 단답 |
| 바로 채점 | 답을 고르면 정답, 해설, 사진 속 근거 문장 |
| 오답노트 | 틀린 문제 자동 저장, 다시 맞히면 졸업 |
| 인증 카드 | 점수와 캐릭터를 담은 공유 이미지 |

## 5. 신뢰를 지키는 장치

| 장치 | 이유 |
|---|---|
| 근거 문장 표시 | 문제가 사진 속 어디에서 나왔는지 확인할 수 있다 |
| "이 문제 이상해요" | 틀린 문제를 바로 신고하고, 신고 비율을 품질 지표로 본다 |
| "AI 출제" 표시 | 생성형 AI 결과임을 알린다 (앱인토스 정책) |
| 사진 저장 안 함 | 문제를 만든 뒤 바로 버린다 |
| 개인정보처리방침 | AI 처리 업체와 국외 이전 사항을 공개한다 |

## 6. 차별점

1. 답이 아니라 문제를 준다
2. 설치나 요청 작성 없이 사진 한 장으로 시작한다
3. 틀린 문제만 다시 푸는 흐름이 있다
4. 올해 수능과 세법 교재로 검증해 정답 오류 0건 (105문제 기준)
