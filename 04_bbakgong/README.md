# 빡공

> AI한테 답 받지 말고, 문제 받자.
> 공부한 필기나 교재를 찍으면 그 내용으로 문제를 내고, 틀린 문제는 오답노트로 다시 풀게 하는 토스 미니앱

| 항목 | 내용 |
|---|---|
| 대상 | 대학생, 공무원 · 자격증 수험생 (만 19세 이상) |
| 출시 | 2026.11.26, 운영 중 |
| 이용 | 토스 앱에서 "빡공" 검색 |
| AI | Claude Opus 5.5 (4개 모델 비교 후 선택) |
